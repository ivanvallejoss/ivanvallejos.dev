01

Contexto

La agencia manejaba su cartera en planillas, con las fotos de cada propiedad repartidas en carpetas compartidas. Buscar por zona implicaba memoria del equipo, y cada publicación se armaba a mano.

ANTES
Planillas por agente, sin fuente única Fotos en carpetas, sin vínculo a la propiedad Búsqueda por zona de memoria
DESPUÉS
Una base compartida por todo el equipo Fotos en object storage, atadas a cada ficha Búsqueda geográfica en la base
02

Arquitectura

Navegador — equipo de la agencia │ └─ Nginx · TLS └─ Django + Gunicorn — panel, API interna ├─ PostgreSQL + PostGIS — propiedades, zonas ├─ Redis — broker │ └─ Celery worker — imágenes, tareas │ └─ Cloudflare R2 — fotos └─ Sentry — errores, performance todo en un VPS Linux · Docker Compose
